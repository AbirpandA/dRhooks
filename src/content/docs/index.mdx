dRhooks is a small collection of production-ready React hooks and UI components built to sit next to [shadcn/ui](https://ui.shadcn.com). It is not a package: when you add an item, the source is copied into your project and from then on it is yours to read, change, and delete.

## How it works

Every hook and component is published as a registry item. The shadcn CLI downloads the item, installs any npm packages it needs, and writes the files into your project.

```bash
npx shadcn@latest add https://dr-hooks.vercel.app/r/use-debounce.json
```

Hooks land in your `hooks` directory and components in your `components/ui` directory, according to the aliases in your `components.json`.

## Why copy instead of install

- **No dependency to keep up with.** Nothing to upgrade, nothing that can break your build when it releases.
- **Fully editable.** Change the behavior or the styling directly, with no wrapper layers.
- **Only what you use.** Each item pulls in only its own files and packages.
