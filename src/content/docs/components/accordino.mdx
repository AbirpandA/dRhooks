## Overview

The Accordino component is a fully accessible accordion built on top of Radix UI's accordion primitives. It provides an elegant way to organize and present content in collapsible sections with smooth animations. Perfect for FAQs, documentation, settings panels, and any content-heavy interfaces where space is at a premium.

### Key Features

- **Fully Accessible**: Built with Radix UI primitives following WAI-ARIA patterns
- **Smooth Animations**: Elegant open and close animations with CSS transitions
- **Customizable**: All components export for full control over styling
- **Single or Multiple**: Support for single or multiple expanded items
- **Icon Integration**: Built-in chevron icon that rotates on expand
- **Type-Safe**: Full TypeScript support with proper typing

## Usage

### Basic Usage

Create a simple accordion with collapsible items:

```tsx
<Accordion type="single" collapsible className="w-full">
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA design pattern.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionTrigger>Is it styled?</AccordionTrigger>
    <AccordionContent>
      Yes. It comes with default styles that you can customize.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## API Reference

### Accordion

The root accordion component that manages state and behavior.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"single" \| "multiple"` | Required | Whether only one or multiple items can be expanded |
| `value` | `string` | - | The controlled value of the open accordion item(s) |
| `defaultValue` | `string` | - | The default open accordion item value |
| `collapsible` | `boolean` | `false` | Whether items can be collapsed when type is "single" |
| `disabled` | `boolean` | `false` | Whether the accordion is disabled |
| `...props` | - | - | All Radix UI Accordion.Root props |

### AccordionItem

Container for each accordion section.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | Required | Unique identifier for the accordion item |
| `disabled` | `boolean` | `false` | Whether this item is disabled |
| `className` | `string` | - | Additional CSS classes for styling |
| `...props` | - | - | All Radix UI Accordion.Item props |

### AccordionTrigger

The clickable header that expands/collapses content.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | - | Additional CSS classes for styling |
| `children` | `ReactNode` | Required | The trigger text or content |
| `...props` | - | - | All Radix UI Accordion.Trigger props |

### AccordionContent

The content that is shown/hidden when an item is expanded.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `className` | `string` | - | Additional CSS classes for styling |
| `children` | `ReactNode` | Required | The content to display |
| `...props` | - | - | All Radix UI Accordion.Content props |

## Key Concepts

### Animation Details

The Accordino component uses CSS animations for smooth transitions:
- Opening: Smooth slide-down animation with fade-in
- Closing: Smooth slide-up animation with fade-out
- Chevron: Smooth 180-degree rotation on expand/collapse

These animations are hardware-accelerated for optimal performance.

### Accessibility

Built on Radix UI's accordion primitives, Accordino follows WAI-ARIA guidelines:
- Proper keyboard navigation (Arrow keys, Enter, Space)
- Screen reader announcements for expanded/collapsed states
- Focus management and visible focus indicators
- Semantic HTML structure

### Styling Architecture

The component uses:
- Base Tailwind classes for default styling
- Border utilities for structure
- Transition classes for smooth animations
- Transform utilities for the chevron rotation
